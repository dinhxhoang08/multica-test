# Repository: multica-test

## Purpose
A simple Todo List application built with Vanilla JavaScript, HTML, and CSS. It allows users to add tasks, mark them as completed, and delete them.

## General Setup
The project is a static web application. No build steps or complex installations are required.
- Clone the repository.
- Open `index.html` in any modern web browser to run the application.

## Repository Structure
- `index.html`: Defines the HTML structure and user interface.
- `style.css`: Contains the CSS styling for the application.
- `script.js`: Implements the application logic using Vanilla JavaScript.
- `README.md`: The original documentation for the project.

## CI/CD and Checks
There are no GitHub workflows or automated CI/CD checks (e.g., linters, pre-commit hooks) configured in this repository.
