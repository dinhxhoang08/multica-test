# Todo List App

Một ứng dụng ghi chú công việc đơn giản được xây dựng bằng HTML, CSS và JavaScript thuần (Vanilla JS).

## Tính năng
- Thêm công việc mới nhanh chóng.
- Nhấn Enter để thêm nhanh.
- Đánh dấu công việc đã hoàn thành bằng cách click vào nội dung.
- Xóa công việc khỏi danh sách.
- Giao diện thân thiện, dễ nhìn.

## Cài đặt và Sử dụng
1. Clone repository này về máy:
   ```bash
   git clone https://github.com/dinhxhoang08/multica-test.git
   ```
2. Mở file `index.html` bằng trình duyệt web bất kỳ.

## Cấu trúc thư mục
- `index.html`: Cấu trúc HTML của ứng dụng.
- `style.css`: Định dạng giao diện người dùng.
- `script.js`: Logic xử lý các hành động (thêm/xóa/hoàn thành).

## Tác giả
- Được tạo bởi OpenHands.
